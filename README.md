
# 🌐 Medium-Scale Network Design & Implementation

A complete medium-scale network architecture designed and simulated using **Cisco Packet Tracer**.

## 📌 Architecture Highlights
- **Core Router:** Serves as the central gateway connecting multiple network segments.
- **Switching Topology:** Redundant switch setup using VLANs for network segmentation.
- **End Devices & Servers:** Integrated DHCP, DNS, and Web servers serving client PCs.

## 🛡️ Security & Features
- **VLAN Segmentation:** Traffic isolation between departments for enhanced network security.
- **IP Addressing Scheme:** Subnetted IPv4 addressing plan for efficient IP utilization.
- **Routing Protocols:** Configured static/dynamic routing across all network nodes.

## 🧰 Tools Used
- **Cisco Packet Tracer**
- **Computer Networking Principles (OSI Model, TCP/IP, Subnetting)**

## 📂 File Structure
- `Network_Topology.pkt`: Packet Tracer source file.
- `Documentation/`: IP Addressing table and network diagram screenshots.
